## Get started with Payna

Payna turns a natural-language request or slash command into a reviewable preview. A transaction runs only after explicit user confirmation.

## Choose the right mode

Use **Payna mode** for wallet, balance, pay, transfer, bridge, and swap actions. Use **AskPayna** for Web3, Circle, Arc, crypto, and L1/L2 knowledge.
