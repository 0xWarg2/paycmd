## Two support layers

A network can be listed by Circle Gateway while Payna's current Circle Wallet SDK cannot sign transactions on it. The table below is generated from application configuration to prevent documentation drift.

## Read the table

**Gateway listed** means Payna knows the domain and USDC contract. **Wallet SDK operations** means the current SDK exposes the blockchain mapping required by the SCA and signing flow. Do not infer that every command works merely because a network appears in the Gateway list.
