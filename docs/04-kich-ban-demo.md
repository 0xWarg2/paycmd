# Kịch Bản Demo

## Demo 1: Payment

1. Gõ `/`.
2. Chọn `/pay 50 USDC to Minh`.
3. Xem preview ở panel phải.
4. Bấm confirm.
5. Chat báo command đã queued.
6. Sau vài giây notification xuất hiện.
7. Xem command detail và tx hash demo.

## Demo 2: Missing Field

1. Gõ `/pay 50 USDC`.
2. Assistant hỏi người nhận.
3. Bổ sung command đầy đủ.
4. Tạo preview.

## Demo 3: Budget

1. Gõ `/createbudget Marketing 500`.
2. Preview tạo ngân sách.
3. Confirm và xem notification.

## Demo 4: Schedule

1. Gõ `/schedule 25 USDC monthly to Minh`.
2. Preview lịch trả định kỳ.
3. Confirm và xem trạng thái queued.
